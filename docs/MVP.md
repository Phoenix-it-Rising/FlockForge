# MVP (Version 0.1)

## Goal

Create a playable creature collection game where players can:

- Hatch creatures
- Discover creature parts
- Track collection progress
- Store creatures
- Prevent duplicate storage

## Features

### Creature System

Each creature contains:

- Head
- Body
- Wings

### Hatch System

Players may hatch a random creature.

### Collection System

The game tracks discovered parts.

### Storage System

Players can store creatures in a lamp.

Capacity:

95 creatures

### Duplicate Prevention

When enabled in settings:

A creature may only be stored once if its combination of parts already exists.
