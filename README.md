# FlockForge

A fan-made creature breeding and collection game inspired by Clusterduck.

Built with:

- Unreal Engine 5
- C++
- Blueprints
- GitHub

## Current Status

Planning Phase

## Features

- Creature collection
- Breeding
- Collection tracking
- Duplicate prevention
- Dream creature planner
- Breeding recommendation engine
