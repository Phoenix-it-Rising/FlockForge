# FlockForge

Breed. Collect. Discover.

FlockForge is a creature collection and breeding game centered around discovering rare sheep mutations, managing bloodlines, and completing genetic collections.

## Core Gameplay

- Hatch sheep
- Breed sheep
- Discover mutations
- Complete collections
- Unlock regions
- Expand pastures
- Build legendary bloodlines

## Key Features

### Genetic Encyclopedia

Track:

- Traits discovered
- Bloodlines discovered
- Mutation rarities
- Breeding combinations

### Breeding Assistant

- Trait targeting
- Breeding suggestions
- Best-pair recommendations
- Missing-trait analysis

### Smart Storage

- Duplicate prevention
- Collection management
- Search and filtering

### Pasture Builder

- Fences
- Barns
- Decorations
- Region expansion

### Bloodline Factions

- Nature
- Arcane
- Mechanical
- Elemental
- Cosmic
